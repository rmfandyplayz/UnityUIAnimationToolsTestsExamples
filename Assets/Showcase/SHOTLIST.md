# Showcase shot list

Generated by **Tools → UI Anim Lab → Build Showcase → Write SHOTLIST.md** from the frames in `Assets/Showcase/Scenes`. Don't edit by hand: change the builders in `Assets/Showcase/Scripts/Editor/Builders` and rebuild.

**Recording a GIF:** open the page's scene, set the Game view to a 16:9 resolution (1920 x 1080 or 1280 x 720), enter play mode. The board starts focused on frame 1; **Tab** moves to the next frame, number keys jump. With a frame focused: **Space** plays it, **R** puts it back, **L** loops it. Frames with buttons or hover can also be used directly with the mouse.

**Screenshots of the Editor:** select the frame (or the object named under Watch) out of play mode; the frame's own Inspector repeats these directions.

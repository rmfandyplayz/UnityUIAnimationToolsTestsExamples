# UI Animation Tools: Tests and Examples

The test ground and showcase for [UI Animation Player](https://github.com/rmfandyplayz/UnityUIAnimationTools/wiki).

- **`Assets/UnitTests`**: hand tests. Eleven scenes of labelled tiles, one category each.
- **`Assets/Showcase`**: one scene per wiki page, with frames set up for GIFs and screenshots.

## Setup

1. Clone this repo **next to** `UnityAnimationTools`. The package is linked from there (`file:../../UnityAnimationTools/DOTweenAnimationPlayer`), so tests run against your working copy of the tool.
2. Open the project with Unity 6000.3.25f1.

DOTween Pro and TextMesh Pro's essentials are already set up in the project.

## Unit tests

Open a scene in `Assets/UnitTests/Scenes`.

| Scene | Covers |
| --- | --- |
| 01 Step Types | Every step type, one tile each |
| 02 Timing and Endpoints | After / With, Delay, From / To and the three modes, Apply From Values Immediately, Loops |
| 03 Easing, Paths and Stylised Motion | Eases, custom curves, movement paths, Play At Custom FPS, Snapping |
| 04 Playback and Interrupts | Interrupt Others, stopping, replaying, punch spam, chaining, Kill On Disable, unscaled time (play mode) |
| 05 Code API | `Play` and its end reasons, `SetTo` / `SetFrom`, `IsPlaying`, `ApplyFromState`, `CaptureBaseline`, `SetShared` (play mode) |
| 06 Targets and Animation Sets | Target slots and paths, sets, overrides, each player's own On Complete, Save as Animation Set |
| 07 Inspector and Authoring | Headers, menus, `+` defaults, copy / paste, mirroring, the type check, the pop-out window |
| 08 Preview | The edit-mode preview, and how carefully it treats the scene |
| 09 Recording | Recording values from a pose (the old R1-R12) |
| 10 Scene Gizmos and Path Editor | Drawings, draggable handles, the selected step, Edit Path in Scene |
| 11 Edge Cases and Warnings | Things that go wrong on purpose |

Every tile has:

- a title and a one-line summary;
- what to watch;
- how to test it;
- what should happen, in yellow.

Badges in a tile's top-right corner say what the test needs: PREVIEW, PLAY MODE, INSPECTOR, SCENE VIEW, CONSOLE or POP-OUT.

**Select a tile**: its Inspector shows the same directions at the top, with buttons that select the objects to watch, and its UI Animation Player underneath. In the Scene view, pan and zoom as usual.

**In play mode:**

| Input | Does |
| --- | --- |
| Right-drag | Pan |
| Wheel | Zoom |
| Tab / Shift+Tab | Next / previous tile |
| 1-9 | Jump to a tile |
| F | Focus the tile under the cursor |
| Home | Show every tile |
| H | Hide or show the index bar |

## Showcase

`Assets/Showcase/Scenes` holds one scene per wiki page, in sidebar order. Each frame is 960 x 540 (16:9).

1. Set the Game view to 1920 x 1080 or 1280 x 720.
2. Enter play mode. The board focuses frame 1, which fills the view exactly.
3. With a frame focused:
   - **Space** plays its demonstration;
   - **R** puts it back;
   - **L** loops it, for a seamless GIF.
4. Tab moves to the next frame.

Frames meant for Editor screenshots (Inspector, Scene view, menus) say so in their Inspector. **`Assets/Showcase/SHOTLIST.md`** lists every shot: what it shows, what to capture, and where it goes on the page.

## Rebuilding

The scenes are generated by editor scripts. **Tools → UI Anim Lab** has:

- **Build Unit Tests** and **Build Showcase**: one item per scene, plus Build All;
- **Generate Shared Assets**;
- **Smoke Check All Scenes**: plays every animation in edit mode and reports warnings and exceptions;
- **Inspector Check All Scenes**: draws every Inspector and reports exceptions.

> [!WARNING]
> Rebuilding a scene replaces it, so hand edits to it are lost. Put lasting changes in its builder, under `Assets/UnitTests/Scripts/Editor/Builders` or `Assets/Showcase/Scripts/Editor/Builders`.
